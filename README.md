# Landing Page - HTML/CSS Project

A modern, responsive landing page built entirely with HTML5 and CSS3 as part of learning front-end web development.

## 📌 Project Overview

The main objective of this project is to design and structure a complete landing page by applying the core fundamentals of HTML and CSS.

This project places a strong emphasis on mastering **Flexbox**, which is used to build layout structures, align elements, and manage spacing between components.

## 🚀 Key Concepts Covered

- **HTML5**: Semantic document structuring (`<header>`, `<main>`, `<section>`, `<footer>`, etc.).
- **CSS3**:
  - Styling fonts, colors, and margins.
  - Understanding the CSS cascade and selector specificity.
  - **Flexbox**: Vertical and horizontal alignment (`justify-content`, `align-items`), managing flex containers (`flex-direction`, `flex-wrap`, `gap`), and overall page layout.
